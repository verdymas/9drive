# Phase 06 - Telegram User Workflow

Use PLAN MODE first.

Review Telegram commands so users can work with the 9drive logical filesystem without Telegram Topics representing folders.

Where compatible, support operations such as:

    /upload Projects/APP-V/docs
    /ls Projects/APP-V/docs
    /move Projects/APP-V/docs/a.pdf Projects/APP-V/archive/a.pdf

Manual files without metadata should use the existing Inbox/fallback flow.

Keep commands concise and reusable. Do not require a Telegram Topic per folder.

Plan, report, approve, then execute.
