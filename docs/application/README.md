# Application Documentation

This folder describes application behavior. Choose a subfolder based on the type of question:

- `domain/` — concepts and invariants that must be preserved.
- `features/` — entry points and implementation details for a specific capability.
- `integrations/` — boundaries with external providers and services.
- `workflows/` — end-to-end sequences spanning multiple modules.

For most coding tasks, read only **one feature document plus one related domain or workflow document**.
