# Integration: S3-Compatible Storage

## Providers
AWS S3 and custom endpoints such as MinIO, R2, Wasabi, or B2 can be used through the AWS SDK S3 client.

## Config
`S3StorageConfig` stores bucket, region, endpoint, `forcePathStyle`, prefix, optional quota, and encrypted access credentials.

## Core Files

- `backend/src/modules/s3/s3.service.ts`
- `backend/src/modules/connected-accounts/connected-account.routes.ts`
- `backend/src/modules/sync/sync-s3.ts`
- upload/file/folder modules for provider-specific branches.

## Filesystem Mapping
S3 has no real folders. Object prefixes/keys must remain consistent with logical folder materialization and reconciliation.
